# MRI-Image-Quality-Assessment
MRI image quality assessment and artifact prediction using machine learning.

## Overview

This project explores machine-learning-based assessment of MRI image quality using quantitative image features. Controlled noise and blur are applied to brain MRI images to create simulated quality levels, which are classified using traditional machine-learning models.

## Problem Statement

MRI image degradation can affect the visibility of anatomical structures and the reliability of downstream image analysis. This project investigates whether handcrafted image features can distinguish between different levels of simulated image degradation.

## Methodology

1. Load and inspect brain MRI images.
2. Generate three versions of each image: original, moderately degraded, and severely degraded.
3. Extract quantitative image features.
4. Split data by original image to prevent related image versions from appearing in both training and test sets.
5. Train and compare Logistic Regression and Random Forest classifiers.
6. Evaluate model performance and visualize feature importance.

## Features Extracted

- Mean, median, and standard deviation of intensity
- Intensity contrast
- Shannon entropy
- Laplacian variance for sharpness
- Edge density
- Mean gradient magnitude
- Intensity percentiles

## Models and Results

| Model | Accuracy | Weighted F1 |
|---|---:|---:|
| Logistic Regression | 94.67% | 0.9468 |
| Random Forest | 98.67% | 0.9866 |

Random Forest performed better than Logistic Regression in this experiment.

## Technologies Used

Python, NumPy, Pandas, OpenCV, scikit-image, Matplotlib, Seaborn, scikit-learn, and Jupyter Notebook.

## Limitations

The quality labels are generated using controlled image degradation rather than expert annotations of real clinical MRI artifacts. The results therefore measure the ability to distinguish the simulated degradation levels, not clinically validated MRI quality. The extracted features are generic image statistics and are not definitive MRI-specific quality metrics.
